3. **Wire only confirmed supported event families to existing compositors:** first Room35 known object state selection + CYCL initial phases. ## Explicit implementation guardrails from the final spelunk

- **Named interactive object ≠ image owner name.** Room22 named object239 has zero stored IMxx states; four unnamed objects235/236/237/240 carry relevant visual states. Build IDs from actual **CDHD and IMHD**, not OBCD/OBIM order or nearby OBNA text.
- **Head animation original-versus-fixed** is not a cosmetic export switch. ScummVM optional `kEnhMinorBugFixes` skips precisely 32 Room22 local201 source bytes at the third object237 draw when Bit129 is already set. Separately `kEnhGameBreakingBugFixes` changes Bit70/69 conditional truth in Room22 local202 based on inventory/story state. Record engine enhancement configuration as provenance.
- **Palette data present ≠ executed or visible:** 127 original CYCL entries, 91 two-color swaps, 32 with repeated RGB values but not a shortened rotational period; seven source cycles have no RMIM/OBIM overlap. Room72 local204 exists but caller remains unknown. Palette intensity scripts49/54 can change ranges192..207/208..255 while a room has **zero populated CYCL**.
- **Scripts may draw at dynamic positions**, set states/classes, start other scripts, chain scripts, yield, or run under pseudo-room logical IDs. Treat timing and execution as **unknown** until observed; don't create 24 duplicate physical room images for 24 pseudo-room aliases.
- **Test and diagnostic honesty:** source-only disassembly alignment < official descumm agreement < actual engine execution < native index and palette match. Report unsupported/invalid/missing separately; do not disguise partial implementation as successful generic reconstruction.
